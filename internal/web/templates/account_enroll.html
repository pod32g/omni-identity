Enroll a device

Give a Linux machine its own identity under your account. It generates a key locally; the private key never leaves it.

2 · Install and enroll

On the machine to enroll, as root:

ARCH=$(uname -m | sed 's/x86_64/amd64/;s/aarch64/arm64/')
curl -fsSLo omni-enrollment {{.Issuer}}/downloads/omni-enrollment-linux-$ARCH
sha256sum omni-enrollment                     # compare with the table above
sudo install -m 0755 omni-enrollment /usr/local/bin/omni-enrollment
sudo omni-enrollment enroll --issuer {{.Issuer}}{{if .Insecure}} --allow-insecure-http{{end}}

The command prints a link and a QR code. Open it here, signed in as {{with .Me}}{{.Username}}{{end}}, and approve the device. It then appears under My Devices. On a machine that has a browser, add --browser to approve in that browser directly instead of using a code.

{{if .Insecure}}
This server's issuer uses plain http://. The agent refuses that unless --allow-insecure-http is passed; use it only on a private network you trust.
{{end}}
3 · Optional: Linux login

To sign in to that machine with your Omni account (with an offline password for when this server is unreachable), install the PAM module and the systemd unit from the sources tarball, then enable the daemon:

curl -fsSL {{.Issuer}}/downloads/omni-enrollment-endpoint.tar.gz | tar -xz
make -C endpoint/pam && sudo make -C endpoint/pam install
sudo install -m 0644 endpoint/systemd/omni-enrollment.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now omni-enrollment

Then add auth sufficient pam_omni.so and account sufficient pam_omni.so above the pam_unix lines of the PAM services you want (e.g. /etc/pam.d/sshd). Keep a local administrator account: it always authenticates through pam_unix.
